# SIASAT — Landing Page Prototype

Prototype landing page untuk **SIASAT (Sistem Analisis Strategi)**.

> **Ubah histori transaksi jadi siasat bisnis.**

SIASAT ditujukan untuk bisnis **Retail, F&B, atau UMKM** yang memiliki histori transaksi berbasis pelanggan. Untuk analisis RFM, data minimum yang dibutuhkan adalah:

- Nama / ID pelanggan
- Tanggal transaksi
- Nilai transaksi

Landing page ini berfokus pada edukasi kesiapan data, value proposition SIASAT, preview segmentasi pelanggan, dan alur analisis RFM.

## Run locally

```bash
npm install
npm run dev
```
